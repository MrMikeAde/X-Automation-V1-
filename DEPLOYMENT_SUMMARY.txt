QUICK START (Choose One)
=======================

Option A: VERCEL (Free, Recommended) - 5 Minutes
  1. Push to GitHub
  2. Go to vercel.com → Import repo
  3. Add env var: GROQ_API_KEY=gsk_your_key
  4. Click Deploy
  5. Done! Your app is live.

Option B: DOCKER (Full Control)
  1. docker build -t naija-trend-banger .
  2. docker run -p 3000:3000 -e GROQ_API_KEY=gsk_your_key .
  3. Open http://localhost:3000

Option C: LOCAL (Testing)
  1. npm install
  2. echo "GROQ_API_KEY=gsk_your_key" > .env.local
  3. npm run dev
  4. Open http://localhost:3000

TROUBLESHOOTING
===============
Error: "Invalid API key"
→ Get fresh key from console.groq.com/keys

Error: "Trends page down"
→ Uses demo trends automatically, wait 1-2 min

Error: "Too many requests"
→ Rate limited, wait 60 seconds

Error: "502 Bad Gateway"
→ Check Vercel Function Logs, verify API key

App won't load
→ Check browser console (F12), refresh page
