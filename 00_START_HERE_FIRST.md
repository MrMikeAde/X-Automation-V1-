## What It Does (30 seconds)

1. **Fetches** trending topics in Nigeria from public sources
2. **Generates** authentic Naija-style viral tweets using Groq AI
3. **Shows** tweets in a beautiful UI with copy/share/refresh features

**Users only need:** Groq API key (free at [console.groq.com/keys](https://console.groq.com/keys))

---

## Deploy in 3 Steps (15 minutes)

### Step 1: Get Groq API Key (5 min, Free)
- Go to [console.groq.com/keys](https://console.groq.com/keys)
- Sign up (free) or log in
- Create API key: `gsk_xxxxxx`

### Step 2: Deploy to Vercel (5 min, Free)
- Push code to GitHub
- Go to [vercel.com](https://vercel.com)
- Import repo → add `GROQ_API_KEY` env var → Deploy

### Step 3: Test (1 min)
- Open your live URL
- Settings → paste Groq key
- "Fetch Trends" → Done!
